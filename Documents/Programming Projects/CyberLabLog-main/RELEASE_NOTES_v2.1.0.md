# CyberLab Case Tracker v2.1.0

## Highlights
- Export success dialogs now show the full saved path in the body and use short, readable titles.
- Optional rotating personalities for "Report saved" confirmations (professional, friendly, snarky, fun).
- Automatic SQLite backups created on close with 56-day retention.
- About tab refreshed: features, dynamic data paths, app version, and a brief How-To per tab.
- Notify-only update check wired to GitHub Releases (About button + silent on startup).
- Packaging: PyInstaller spec uses digital.ico; build instructions and signing script added.

## Changes
- Added helper for concise messagebox titles; moved details into message body to avoid truncated titlebars.
- Standardized export dialogs across PDF/XLSX flows; always includes "Saved to:" path.
- ReportLab PDF header/footer improved; page X of Y footer with generated by/date.
- Settings polish and path management consistency.
- README and PACKAGING docs updated.
